Lave-vaisselle GE — code d’erreur C4

The unit refilled twice after a power loss, suggesting a stuck or failed float switch.

marque GE appareil Lave-vaisselle marché US composant float switch catégorie sensor gravité degraded

Aucune réparation classée n’est encore fournie pour ce code ; ApplianceDB range l’élément float switch dans la catégorie de cause sensor. La gravité est classée degraded — l’appareil continue de fonctionner, mais pas correctement.
