Four / cuisinière Whirlpool — code d’erreur F2E1

A fault involving the user interface or keypad, the control, or their wiring was detected.

marque Whirlpool appareil Four / cuisinière marché US composant keypad catégorie control_board gravité degraded

ApplianceDB classe 1 réparation pour ce code, avec en tête « Power-cycle then service ». Cette solution prioritaire est une intervention de difficulté moyenne à faire soi-même, portant sur : keypad. La gravité est classée degraded — l’appareil continue de fonctionner, mais pas correctement.

Étapes de réparation classées

1. Power-cycle then service

Switch the breaker off for one minute and restore power; if the keypad code returns, service the interface, control, or wiring.

moderate · critère : manufacturer first
