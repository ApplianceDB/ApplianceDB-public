Lave-linge Beko — code d’erreur E05 (UK)

The water-level pressure switch is reading incorrectly.

marque Beko appareil Lave-linge marché UK composant pressure switch catégorie sensor gravité degraded

Aucune réparation classée n’est encore fournie pour ce code ; ApplianceDB range l’élément pressure switch dans la catégorie de cause sensor. La gravité est classée degraded — l’appareil continue de fonctionner, mais pas correctement.
