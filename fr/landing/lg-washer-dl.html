Lave-linge LG — code d’erreur DL

The door-latch switch is not reading the door as closed.

marque LG appareil Lave-linge marché US composant door latch switch catégorie door_lock gravité stop failure

ApplianceDB classe 1 réparation pour ce code, avec en tête « Clear the door and reset ». Cette solution prioritaire est une intervention facile à faire soi-même, portant sur : door latch switch. La gravité est classée stop failure — l’appareil s’arrête jusqu’à la disparition du défaut.

Étapes de réparation classées

1. Clear the door and reset

Remove anything caught in the door, unplug for ten seconds, restore power, and retry the cycle.

easy · critère : manufacturer first

Provenance : faits redérivés d’une fiche officielle du fabricant — LG USA Support — Washer Error Code List. Les significations et les étapes sont une paraphrase originale ; rien n’est reproduit mot pour mot.
