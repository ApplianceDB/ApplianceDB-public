Lave-vaisselle Frigidaire — code d’erreur CL

The door is open or not securely closed.

marque Frigidaire appareil Lave-vaisselle marché US composant door latch catégorie door_lock gravité stop failure

Aucune réparation classée n’est encore fournie pour ce code ; ApplianceDB range l’élément door latch dans la catégorie de cause door lock. La gravité est classée stop failure — l’appareil s’arrête jusqu’à la disparition du défaut.

Étapes de réparation classées

Aucune solution utilisateur n’est encore fournie pour ce code — consultez la fiche du fabricant en lien ci-dessous ou faites appel au service après-vente.

Provenance : faits redérivés d’une fiche officielle du fabricant — Frigidaire Owner Support — Dishwasher Error Codes and Alarms Guide. Les significations et les étapes sont une paraphrase originale ; rien n’est reproduit mot pour mot.
