GE Backofen / Herd — Fehlercode FC

A component in the door lock circuit failed.

Marke GE Gerät Backofen / Herd Markt US Bauteil door lock circuit Kategorie door_lock Schweregrad stop failure

ApplianceDB listet für diesen Code 1 priorisierte Reparatur, an erster Stelle „Reset then request service“. Diese vorrangige Lösung ist ausschließlich Fachleuten vorbehalten, keine Selbstreparatur; betroffen ist door lock circuit. Der Schweregrad ist als stop failure eingestuft — das Gerät stoppt, bis der Fehler behoben ist.

Priorisierte Reparaturschritte

1. Reset then request service

Switch the breaker off for a minute or two; if the door-lock circuit code returns, request service.

professional only · Grundlage: manufacturer first
