LG Refrigerator — Error Code GF

The water flow sensor is faulty or the supply pressure is low.

brand LG appliance Refrigerator market US component flow sensor category water_supply severity degraded

ApplianceDB ranks 1 repair for this code, led by “Check flow and pressure”. That top fix is a moderate-difficulty DIY job, involving the flow sensor. Severity is classified as degraded — the appliance keeps running but not correctly.

Ranked repair steps

1. Check flow and pressure

If the ice maker overfills the flow sensor may have failed; if household water pressure is low, raise it. Otherwise request service.
