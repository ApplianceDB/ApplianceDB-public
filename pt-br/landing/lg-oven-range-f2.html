Forno / fogão LG — código de erro F2

The upper oven thermistor is reporting a fault.

marca LG aparelho Forno / fogão mercado US componente oven thermistor categoria sensor gravidade degraded

O ApplianceDB prioriza 1 reparo para este código, encabeçado por “Clear and reset”. Essa solução principal é um reparo fácil de fazer você mesmo, envolvendo o componente oven thermistor. A gravidade é classificada como degraded — o aparelho continua funcionando, mas não corretamente.

Etapas de reparo priorizadas

1. Clear and reset

Press Clear/Off and retry; if the thermistor code persists, cycle the breaker for thirty seconds and request service if it returns.

easy · base: manufacturer first
