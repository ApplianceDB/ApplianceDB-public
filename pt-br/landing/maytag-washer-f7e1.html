Lavadora Maytag — código de erro F7E1

A motor speed-sensing error was detected.

marca Maytag aparelho Lavadora mercado US componente drive motor categoria motor gravidade stop failure

O ApplianceDB prioriza 1 reparo para este código, encabeçado por “Check bolts and load”. Essa solução principal é um reparo de dificuldade moderada para fazer você mesmo, envolvendo o componente drive motor. A gravidade é classificada como stop failure — o aparelho para até que a falha seja eliminada.

Etapas de reparo priorizadas

1. Check bolts and load

Confirm all shipping bolts were removed and the drum is not overloaded, then clear the code with Pause/Cancel twice and Power once.

moderate · base: manufacturer first
