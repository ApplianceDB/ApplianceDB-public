Lavadora Hotpoint — código de erro F16 (UK)

A door lock fault was detected on specific models.

O ApplianceDB prioriza 1 reparo para este código, encabeçado por “Replace the door interlock”, com peças observadas a £14.49–£28.10 em 2026. Essa solução principal é um reparo avançado para fazer você mesmo, envolvendo o componente door interlock. A gravidade é classificada como degraded — o aparelho continua funcionando, mas não corretamente. 1 peça de reposição OEM está documentada para os reparos desta página, incluindo Washing Machine Door Interlock.

Etapas de reparo priorizadas

1. Replace the door interlock

After confirming nothing blocks the door and a reset does not clear the fault, disconnect power and replace the door interlock (the component this code attributes).
