# Contributing to ApplianceDB

Corrections are welcome — accuracy and honest provenance are the whole point.

## Reporting a wrong code, meaning, or fix

Open a GitHub issue including:

1. The `(brand, appliance_type, code)` identity of the record.
2. What is wrong (meaning, component, cause category, severity, or fix step).
3. **A source URL** supporting the correction — this is required. The
   manufacturer's own support page is preferred; an independent repair
   reference is accepted only where no official listing can be fetched, and
   is flagged `aggregator_listing`. Never forums or model memory.

## Ground rules

- **No verbatim manufacturer text.** Proposed meanings/steps must be original
  paraphrase.
- **No fabricated data.** A correction without a fetchable source URL cannot be
  merged.
- **NULL over guess.** Do not add costs or part numbers without a recorded,
  verifiable price observation.
- **Coverage honesty.** New `(brand, appliance_type)` pairs must reach ≥ 10
  verified codes to ship.
