Horno / cocina GE — código de error F4

The oven temperature sensor needs replacement.

marca GE electrodoméstico horno / cocina mercado US componente oven sensor categoría sensor gravedad degraded

ApplianceDB prioriza 1 reparación para este código, encabezada por “Reset then replace the oven sensor”. Esa primera solución es un trabajo exclusivo para profesionales, no de bricolaje, que afecta a: oven sensor. La gravedad está clasificada como degraded: el electrodoméstico sigue funcionando, pero no correctamente.

Pasos de reparación priorizados

1. Reset then replace the oven sensor

Switch the breaker off for a minute or two; if the code returns, the oven temperature sensor needs replacement.
